# GlyphForge P0～P1-B 集成审计

审计日期：2026-10-30（Asia/Shanghai）。审计基线：`d57f40b`，分支 `codex/p1b-relations`，加本次未提交修复。源文件指纹见 [manifest.json](audit/manifest.json)。本报告覆盖仓库已经实现的功能，没有开发 P1-C / P1-D，也没有重建项目或变更数据库 schema。

## 结论与实际完成度

- **P0**：资源、图/AST、NameScript、Worker、保存与分享的主要闭环存在；本次发现的导入、执行和版本一致性缺陷已修复。不能据此声称所有规模、环境和边界都已验证。
- **P1-A**：中文算子与文字实验室确实复用执行器，可保存资源并供工作流引用；结构、读音和转换受真实数据覆盖及候选上限约束。自定义映射仍是节点参数，不是独立映射资源。
- **P1-B**：关系行、编辑器、配对模板、六种可编辑普通工作流配方确实可运行；多槽位和一对多在已测路径上保持绑定。**完整关系模型仍未实现**：没有显式方向、权重、标签、备注、来源或专门的反向关系查询（PROJECT-STATUS 的 G02）。
- **P1-C 建议：有条件开始**。可以在本次修复和回归基线上推进普通词库检索、排序与缓存；若涉及关系逆向，先明确 G02 的方向语义及迁移方案。不要将隐含左右顺序当成已支持有向/无向关系。整份 v3.0 产品规划没有完成。

本轮未发现其他已证实且尚未修复的 P0 阻断；这不是不存在未知缺陷的保证。未完成的产品规划与新增程序缺陷分别列出，避免把规划缺项算作本轮已经修复的功能。

## 分模块核验

**P0 数据与执行。** 稳定 resourceId 与 entries/relations 分表真实存在；精确/前缀使用复合索引，界面词条分页 60，资源读取分页 256，输出批次 64，结果列表有界渲染。算子定义、注册执行和图/AST 分层存在；AST 与图最终通过同一个 execute，中文变换复用 transformChinese。AABB/ABBA、嵌套循环、分支、遮蔽、短路、环路拒绝、Unicode 字符簇、复制新节点 ID/内部连线均有回归。没有把“用了 async generator”推断为所有操作都流式：group 是有界蓄水池，排序/筛选当前结果以及文件路径仍会占用内存。

**P1-A 数据与许可。** 抽查明→日/月、思→田/心、未知字符保留、木/木→林、重复部件、拼音多音/声韵、OpenCC 词组、火星文/自定义候选与 Unicode。数据实物为结构 85,238 条记录、笔画 102,998 字、读音 44,348 字；不能将结构记录数当汉字总数。检查 sources.json、生成脚本及 public/licenses 中 CJK Apache-2.0/原 README、Unicode V3、pinyin-pro MIT、OpenCC MIT 和数据 Apache-2.0/第三方说明；生产构建复制许可证目录。未重新下载上游重建数据，也未逐字人工判定结构准确率。反向组字忽略顺序、同音未穷尽、严格现代韵母等既有边界继续有效，没有伪造缺字结果。真实浏览器首页生成没有请求大型中文字典，进入拆字才加载相应数据；静态字典/索引缓存在 Worker 生命周期内复用。

**P1-B 数据链路。** schema 2→3 为加性升级，已有测试用真实 Dexie 升级流程配合 fake-indexeddb 验证旧数据；再次打开、分页、事务去重/编辑合并、删除资源级联均有覆盖。关系端点为行内字符串，没有对普通 Entry 的外键：修改普通词条不会级联改变关系端点，也不存在相应悬空 Entry ID。六配方不是展示占位，均由通用 template/group/pairs 执行，并已有六份可导入文件的执行测试。类型为 associated 的数据不会被当作 antonym。模板 members 作为同一结果输出，槽位在一次绑定中供全部成员共享；文字加工后会清除失效的成员标记。额外验证三槽各两行且左端相同的一对多，八组全部保持行内右端绑定。

**导入与脚本安全。** 检查白名单算子/函数、IR/算子版本、图环路、AST 深度/大小、固定资源 ID、字符串/结果/步数限额；实现没有 eval/new Function。非法连线和损坏快照在写事务前失败；导入资源与工作流由同一事务提交。Worker 终止是实际取消机制，10 秒/300,000 步是计算防护，不是严格堆内存配额或任意 JS 沙箱；当前不接受任意 JavaScript。这里只评估已有协议，未进行完整安全渗透或第三方依赖漏洞扫描。

## 后续架构注意事项

开始 P1-C 时应复用稳定资源 ID、事务版本、统一候选/算子与限额机制。可变词库缓存不能只依赖名称或 React 页面快照；关系反查不能假设所有关系无向；新增索引需要迁移与增删改/恢复测试；保留来源的同时控制历史存储增长。当前深页 offset、整体 JSON 与缺少硬堆内存配额是需测量和权衡的边界，本轮没有为此推倒现有架构。
