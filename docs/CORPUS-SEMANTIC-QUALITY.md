# 六风格生成质量修正

2026-11-11，基线 main `2793ab5`。用户反馈结果不通顺，并要求删除安装词库的页面。本轮在独立 `codex/corpus-semantic-quality` 工作树修改，保留线上 M3 路由与来源字段清理。

## 问题与修正

旧算法将宽泛标签直接做笛卡尔积，整句、食物、动物及单字之间可随意互换。固定种子 42 的已发布便携包可复现「豆子不想上班」「叶飞鸟」「摆烂绝对」「零海盐」；原回归只检查数量、长度、确定性，不能代表中文语义质量。最初四项质量用例全部失败，见 [red.txt](quality/red.txt)。

新版六风格使用独立的 [composition.json](../data/playertrack/composition.json)：词条注明具体槽位，规则声明允许的有序组合，例如口味＋甜点、困倦形容词＋动物、地点＋景象、未寄＋信件、行为＋身份、摄影状态。整句只直出；不再用「modern」「daily」等宽泛标签任意拼接。同一组合内字形重叠会排除。没有足够合规候选时少出或不出，不用错误组合补数量。人工明确批准的关系仍尊重原用户决定。

词条和规则都随 v6 工作流 JSON 导出，节点中只存风格、长度及生成参数。自定义配伍规则也能导入恢复，不偷偷回退到内置规则。原 Worker、图、NameScript、来源追踪、取消预算和 IndexedDB schema 7 沿用。

删除侧栏「FF14 玩家语料词库」及对应安装管理组件，生成首页直接点工作流卡片，再点「生成 ID」。生成偏好放入折叠设置。资源中心、工作流编辑、收藏和离线导入导出保留。

已有浏览器的六风格资源在启动时一次性补齐角色和编辑素材。保留原行及实际观察频次、禁用/拒绝、人工标签/权重、工作流名称/种子/规则和收藏。重复刷新不重复追加、不再递增版本。原提取数据文件未改；新编辑补充明确标记 `origin: editorial`，全部玩家观察频次为 0，不能冒充来自 PlayerTrack 的统计或人工审读通过。
