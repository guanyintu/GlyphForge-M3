2026-11-11。生成首页直接提供六套 FF14 工作流卡片，点击选择，再点击「生成 ID」。原版海都、扩充版、默认及用户已有工作流统一使用卡片；不再保留隐藏的工作流下拉框。

后续反馈已由 [语义质量修正](CORPUS-SEMANTIC-QUALITY.md) 接续：安装管理页面已删除，生成规则及六份便携包已更新。下方测试数量与「保留语料审核入口」描述仅属于 2793ab5 的历史版本。

## 实际交付

- 六套可直接运行的工作流：萌系日常、自然意象、清冷文艺、奇幻角色、趣味潮流、海都潮人。每套沿用独立词库、语料组合与 output 三节点，默认 75 个唯一结果；海都 2～3 字，其余 2～6 字，仍可编辑。
- 第一次点击卡片才安装对应素材与工作流；再次打开复用已保存的名称、种子、规则和词库编辑。跨同页并发请求及 IndexedDB 事务保证单套只建一份。已有语料工作流与导入的便携工作流也可识别复用。
- 网格在宽屏三列、手机两列，提供选中态、风格描述、长度和示例素材；卡片区域可以滚动，工作流较多时可搜索。键盘可用 Tab、Enter、Space。
- 正在打开工作流时暂时禁用生成和其他卡片；运行中、未应用代码草稿期间禁止卡片切换。选取不会自动执行生成，编辑器继续作为二级入口。
- 六份完整 v6 JSON 已放在 `public/workflows/ff14-{cute,nature,literary,fantasy,trend,haidu}.json`，含原词库、完整语料元数据及关系审核状态，可经现有导入器在空库恢复。清单在 `public/workflows/playertrack-manifest.json`，可运行 `node scripts/export-playertrack-workflows.mjs` 复现。
- 保留语料审核入口、词库 JSON 和原海都流程。按最新线上 main / 4875d03 在独立 worktree 接入，保留 M3 来源字段清理、社区路由和公开配置检查；没有以旧 M2 App 覆盖线上。
