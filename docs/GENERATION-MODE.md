# 工作流生成与编辑模式修正

2026-11-09。当前指令优先：普通用户先选择工作流再生成，编辑器在二级入口。之前将「做成工作流」误解为直接展示画布，本轮恢复最初的普通/编辑分离，并对全部工作流共享实现。

## 实现

- App 的 editing 状态只存在于当前会话，初值为 false；打开/刷新不挂载画布、代码、AST、估算器或节点设置。普通模式不会自动执行未选择确认的工作流。
- WorkflowGenerator 仅渲染选择、生成设置及事件；App 的既有 run/Worker 执行实际选中工作流。没有海都独立引擎、词库副本或新增数据库 schema。
- 普通模式显示工作流选择、配方浏览、生成按钮、结果、复制及收藏。含精选节点时，字数、分类、包含/排除直接编辑该节点参数；类别从独立关系资源读取。每次生成默认换种子，可在折叠设置中固定种子和数量。
- 原 Results 共用，普通模式点击名字复制，显示较大的名字卡片；来源、动画与规则等原完整控件仍在编辑模式。最近批次折叠展示，收藏/导出复用原能力。
- 「编辑」挂载原完整编辑器；「返回生成」只切换视图，保留会话中的未应用文本；「保存并返回」先解析/验证、完成原 IndexedDB 写入，再切回生成；失败保持草稿与编辑器。工作流原自动保存继续保留。
- 联网分享仍为关闭；本轮不发任何生产数据库写入，不重置或删除词库、收藏、历史及草稿。

先运行真实 Chromium 的新模式断言，在旧站构建因缺少普通选择界面而失败，保留在 haidu/generator-mode-red.txt。首次新实现 7 项新模式 + 7 项海都均通过；436/436 单元、类型与构建通过。完整冻结回归 436/436 单元、79 项生产 Chromium 通过/3 项联网用例停用跳过、120/120 基准、类型/构建全部通过；另有显式启用测试开关下的旧 M3 Chromium 6/6。冻结门禁归档到原工作区 docs/m2/full-1794166955799；源指纹全部一致。发布结果待本页后续记录，不能沿用 4be727d 的上线结论。

测试覆盖：默认无流程图/代码、任意工作流选择、五列实际生成、二三字/数量/固定种子、名字点击复制、收藏刷新、编辑/保存/返回/刷新、未应用文本保留与非法文本拒绝、手机布局、旧工作流与本地导入导出。原编辑器回归现在显式点击「编辑」入口，原业务断言保留。

限制：未应用的代码文本仍只保留在当前会话；刷新会触发既有未保存提示，但未新增跨刷新文本恢复。工作流图原自动保存继续执行。「保存并返回」不是回滚原编辑事务。用户可以主动打开二级资源、来源、历史等工具。词库玩家审读/真实撞名、Firefox/WebKit/实物低端及整份 v3.0 未完成。
