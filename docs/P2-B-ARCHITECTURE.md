# P2-B 名字变异与创意增强

2026-10-31（Asia/Shanghai）。基于已通过的 P2-A `637333f`；P2-A 不重做。范围取自参考提示词 §8.1，沿用 P2-ENTRY 与 S0-2 契约。

## 入口和执行

结果卡片、列表和我的收藏的「变异 / 继续创作」按钮打开独立创作面板。逐个字符簇显示序号和锁定状态；重复汉字按位置独立锁定。选择八种操作、1～3 步强度、种子、数量、字符池、前后缀与普通替换词库，再生成。每个结果仍使用现有 Results，支持收藏、复制、TXT/CSV/JSON、存为词库、来源详情与下一轮。

`Mutation.tsx` 只组装普通 Workflow：`mutate → 可选 gamecheck → output`。App 使用原执行 Worker、Web Locks、beginRun/appendRunBatch/finishRun、背压、历史留存与硬取消。没有第二个解释器，没有 eval、动态代码或扩展包权限。主画布与代码草稿不会被变异任务覆盖；变异运行快照进入原运行历史。存为词库后，现有 resource 节点、工作流和 P2-A 子图可直接消费。

`mutate` 是零序列输入的内置有界源算子，输入 Candidate 快照通过受限 JSON 标量参数携带。这样旧收藏不需要伪装成当前资源行。模型、执行注册表、S0-2 参数/资源类型检查、节点图、NameScript 图级打印解析、子图定义及分享 manifest 共用契约。它没有 program AST 标量函数签名，也不作为文字实验室单条算子开放；这两个入口没有隐式 Candidate→String 转换。主要参数编辑入口是结果/收藏面板；直接添加默认节点可运行，复杂图级编辑可用 NameScript。

## 字符簇和操作语义

执行时把输入拆为 `{text, locked}` 字符簇 token。锁表示 token 身份，而非后续固定下标：插入/删除可以让位置移动，但锁定内容及锁之间的相对顺序不变。输出记录移动后的锁位置，下轮自动继承。最终重新分簇，并逐 token 检查边界；会让组合音标/ZWJ 合并边界的结果直接丢弃。

| 操作 | 实际语义 |
| --- | --- |
| 替换 | 用字符池中的一个完整字符簇替换随机未锁位置 |
| 插入 | 在字符簇之间插入完整字符簇，包括首尾 |
| 删除 | 删除未锁字符簇，空名字不输出 |
| 前后缀 | 从用 `\|` 分隔的非空词中选一个加在首或尾 |
| 词库替换 | 用所选普通库词条替换一个完全未锁的词；含锁的整个词保持原样 |
| 词序 | 交换两个完全未锁的整词，标点/空白分段不参加交换；不是把词内汉字倒序 |
| 谐音 | 单字调用已有 homophones（带声调、每字32候选），无读音或无异体候选时跳过 |
| 火星文 | 单字调用已有 hanconvert/martian 趣味映射，不声称同义或同音 |

分簇复用 unicode.ts 的 Intl.Segmenter；分词用固定 `zh` word Segmenter。中文词边界是语言工具给出的分段，不是完整语义理解。锁住一个词内任一字会阻止整词交换/替换；其他字符操作仍可编辑其中未锁位置。强度是每次尝试的操作步数，不保证恰好改变相应数量的字符；无效操作、原文、空文和重复结果不输出。

## 确定性与资源

算法参数 `algorithm=1`，32位受控 PRNG，每轮从相同输入和种子重新开始；不读当前时间、不使用 Math.random，不跨轮继承随机状态。顺序、去重和中文候选均固定；相同输入/设置/种子、资源内容版本和算法/内置中文数据版本可重现文本、顺序、parts 与 derivation。新运行的 UUID/时间本来就不同，不属于相同输出身份。较大安全整数种子折叠到低32位，允许不同种子碰撞。

可选替换资源一旦设置就是静态资源依赖，进入原 dependencyIds、版本向量、便携包与资源重绑定。Worker 复用原读取前/逐行版本检查，资源 kind 在读取前校验，即使是空关系库也拒绝。按资源 reader 的种子顺序最多读取前256条，不扫描或缓存完整大库。不建立动态词库、不提供历史资源内容快照。重放前应使用相同版本内容；资源变更需新运行。

Intl Unicode/ICU 版本不同可能改变分簇或词边界；当前实测环境是 Chromium。没有宣称跨 Unicode 实现、跨浏览器版本的逐字节相同输出。更新算法/内置映射时应升级算法版本，不能悄悄改变同版本语义。

## 来源真实性与迭代

派生输出保留历史 `parts` 的资源 ID、文本、版本和来源片段 Pair，不把它们改写成新名字；字典替换追加实际读取的词条来源并去重。顶层 Pair/members 不复制，文本变化后的失效成员身份不会留存。结果卡片及详情明确显示「变异衍生」。

`derivation` 是可选的扁平版本1元数据：轮数、种子、当轮实际操作、输出锁位置、直接父输入的文本/runId/workflowId/seed。当前 Candidate 的 runId/workflowId 由真实新运行赋值；旧工作流身份只放在 parent 引用中，不冒充旧工作流已生成该文本。没有为每条候选递归复制整棵历史树；上游资源片段是素材证据，不等于整条名字的生成证明。

收藏仍按既有文本主键和 S0-1 来源保护保存。当前收藏所引用的变异运行及快照受保护；父运行引用不自动获得永久保护，若被清理，保留的父文本/资源片段仍可解释，但不能保证完整祖先树可回放。来源缺失必须如实理解为缺失，不制造记录。

面板保留最近20个输入/设置/种子/游戏规则/结果快照，可回退到上一轮重新分叉；回退不删除已写历史或收藏。关闭/刷新后不保存面板的撤销栈；已收藏结果、生成记录和运行快照正常持久化，可从收藏再次继续创作。没有无限历史树或跨标签协作。

## 预算和兼容

- 输入/输出最多100字符簇、1024代码单元；输入快照 JSON 最多32768代码单元、128来源片段。其他字符串复用256参数限制，锁JSON最多512；无效类型、锁、操作、算法或轮数直接报 S0-2 参数错误。
- 每轮1～256个结果，最多 `count × 32` 次尝试（最大8192），每次1～3步。共享300000步/10秒；原Worker墙钟watchdog、UI硬终止和64条持久化背压继续生效。全锁、低多样性或游戏规则过滤可返回0项或少于请求数量。
- 替换词缓冲最多256行、65536文字代码单元；中文局部候选缓存最多128键、每键32候选；输出来源超过128片段报预算错误，不静默裁掉事实。主结果256条、撤销栈20轮均有界。内置中文大字典继续由既有懒加载/索引提供；这些逻辑上限不是全浏览器 RSS 或 Worker 峰值内存承诺。
- 原 DB schema6、Workflow IR1、结果文件v1和旧分享包v1～v5继续可读；derivation 为附加可选字段。新算子进入原算子版本清单；旧客户端不支持新算子时应拒绝，不尝试降级为伪造结果。JSON保留完整来源元数据，TXT仅文本、CSV沿用原文本/工作流/种子列。

验收数字、环境、失败夹具修正、隔离提交与未完成边界见 [P2-B 验收](P2-B-VALIDATION.md)。本阶段不关闭动态资源、Mapping、扩展包、任意JS隔离或 G01～G09/Q01～Q03 的其他缺口。
