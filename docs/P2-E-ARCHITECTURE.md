# P2-E：有界来源引用与组合元数据剪枝

日期：2026-10-31（Asia/Shanghai）。基线 `e637beb`，工作分支 `codex/p2-e-lineage`。本阶段交付最小纵向闭环；完整高级剪枝/P2/v3.0仍未完成。[验收](P2-E-VALIDATION.md)记录实际版本与范围。

## 来源契约与真实性

`core/lineage.ts` 定义可序列化 `Lineage={version:1,refs:string[],incomplete:boolean}` 与 `EvidenceClaim={evidence,summary}`。四级证据为 executed（程序真实生成并保存）、matched（独立词条/结构确定匹配）、inferred（潜在组合/拼音/模板等推断）、unknown（无法判定）。逆向证据单独返回，绝不写进 Candidate 的执行引用。

生产执行有 runId 时，图节点在真实 yield 后追加引用；API测试/非持久执行可显式选择 lineage=true。引用内容是 JSON `[scope,path]`：主图 scope=工作流ID，动态资源 scope=`[resource,id,version]`；子图 path 包含实际调用节点路径，扩展追加实际流水线步骤编号。动态资源即使克隆了同一工作流ID，也不会指向另一资源的声明。引用只描述参与当前结果的操作依赖顺序，不是执行次数日志或全树。

运行ID、创建时间、种子、工作流/子图定义、扩展声明和资源版本向量复用既有 RunRecord；不为每个候选复制它们。Candidate.parts 保留必要的真实输入素材快照和版本，notes、Pair/members沿用旧语义。组合、模板、成员分组和词库变异合并有界引用；名字变异的旧来源通过原 Derivation.parent 链接，绝不把父运行执行引用冒充本轮操作。失效Pair/members不恢复。

一个候选最多32条引用、每条384代码单元、合计4096代码单元，超限置 incomplete=true，不改变结果或素材。合并按首次出现保序去重；引用是指向运行共享定义的小字符串，没有递归children。导入验证拒绝未知字段/隐藏树和超限引用。没有以逆向结果或遍历整个工作流推造旧记录的执行路径。

`storage/lineage.ts`只读取选中项的 run + `[runId,text]` generated，存在两者才显示已证实。缺少引用的旧运行仍可证明有保存的生成记录，但逐算子路径不可判断。引用失效时保留标识并显示无法展开；资源缺失/版本变化、扩展缺失/禁用分别提示。静态资源只有版本向量和选中片段，没有历史全集，**不能保证完整重放旧运行**。本地记录/用户恢复备份不是防篡改公证。

## 界面、收藏与保存

结果、收藏、历史与逆向的已保存来源沿用同一详情弹窗。LineagePanel仅在选择一项后挂载；操作/资源列表由details按需展开，最多32条操作/32个诊断片段/256个资源版本，不挂载10k来源树。复制概要包含运行身份、路径、版本、必要输入片段及最终文本；省去无关关系备注、标签和发布者链接，不自动外传。

逆向页增加四级证据概要；明确“真实运行曾生成同名文字”不证明外部输入采用此路径。拼音/归一化在摘要中保守标为候选推断。现有匹配位置、规则、模板和Top-K仍各自展示。

引擎仍按单次运行的text去重，**只保留稳定枚举顺序中的第一条真实路径**，不宣称收集所有同名路径。generated仍以 `[runId,text]` 隔离，不跨工作流合并。收藏旧表以text为唯一键，当前不迁表：另一runId/workflowId的同名收藏显式报错、原收藏保留；用户需去收藏中取消原项后再保存。列表收藏状态按text+runId+workflowId识别。没有把两次运行的来源拼接在一起。

S0-1留存不变：默认20次普通历史、可调0～200，执行中/固定/收藏来源额外保留；父运行不自动永久固定。导出/恢复继续运行备份v1，最多10k结果/32MiB，超限拒绝且不截断数据。来源新字段随生成记录、收藏、JSON结果文件和运行备份保存。便携工作流分享v1～v7仍只携带配方/资源，不冒充历史来源迁移；恢复后重新生成有真实新运行身份。无schema升级、无IndexedDB新表或资产重写。

## 剪枝的等价性证明与适用范围

优化前冻结 `e637beb` engine/operators 于 `src/tests/fixtures/p2e-legacy-*`，仅调整import位置并冻结组合元数据合并。对比三路：旧惰性实现、新实现optimize=false、新实现默认开启。新增lineage独立比较，新旧原有字段逐项相等。

仅融合**同一作用域直接相连的 concat/pattern → filter**。先按原顺序执行所有上游节点、资源读取、两侧循环tick和 transformText/boundedText，得到实际文字，再执行原filter的tick与原Unicode字符簇/包含/排除谓词。确定拒绝时省略 combineCandidates（SourcePart去重、notes合并和组合节点引用分配）；接受时继续原元数据合并和引用追加。过滤tick的异常在原filter节点定位后再传播，文字超限仍在原组合节点定位。

因此，在同样输入、版本、种子且未触发墙钟/外部取消时间差时，保留：输出文本、稳定顺序、parts/notes、Pair/members、去重首路径、结果截断、读取/随机消费、步数与步数预算错误定位。没有通过UTF-16长度猜字符簇长度，组合边界的重音、ZWJ、区域旗帜、CRLF均对实际文字使用原glyphs。未知库长度不用于提前停止；随机或有副作用的上游仍完整消费。拒绝项只跳过纯元数据构造。

这属于**组合元数据构造剪枝**，不是减少逻辑组合枚举次数。适用于来源合并占比较高、拒绝率高的直接组合过滤；全通过、小parts或主要耗时为IDB读取时不保证更快。safePruned是实际省略的组合来源构造次数，主图/子图统计不包含动态资源内部独立计数。没有把未知源count当精确估计。

optimize=false可关闭该局部规则。跨算子/子图调用边界的谓词下推、跳过内层读取、静态长度上界推断、随机/中文/Mapping/扩展内部重排、program AST融合与通用优化器均未启用。没有正则执行平台或全排列缓存。10秒墙钟、用户取消和并发资源变动按实际发生时间生效，优化可能在期限前多消费一些项，**不承诺时间预算下的部分结果完全相同**。

## 预算与后续边界

复用唯一执行器、Worker、背压和P2-A/C/D资源校验。新增引用没有创建执行预算，不改变共享300k步骤/10秒/10k输出/64条批次/1024代码单元文字限制。深子图、动态DAG和扩展不重置预算。Worker仍只是性能和取消隔离，没有任意JS节点、网络插件或压缩分享码。

延期：逐次中间值与program AST内部语句跟踪；完整参数绑定可视化；完整历史资源内容归档/重放；同名多收藏的新键迁移；全部重复路径收集；只读组合规模区间估计；动态内部剪枝计数汇总；能够证明安全的枚举级前缀约束。Worker RSS/绝对峰值、Firefox/WebKit及实物低端未验收。下一步应先选择一个有真实收益且能维持计步/错误/随机消费的枚举级规则，再扩范围。
