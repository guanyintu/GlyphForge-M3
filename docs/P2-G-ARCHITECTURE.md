# P2-G：压缩分享码与安全离线分享

日期：2026-11-01，Asia/Shanghai。基线 `e3e93b9`（P2-F 源码 `7af6379`）。实际验收与失败记录见 [验收](P2-G-VALIDATION.md)。P2-F 的枚举级优化 NO-GO 未解除；不代表完整 P2/v3.0 完成。

## 独立传输协议

`GFS1.deflate.<UTF-8字节数>.<SHA-256小写hex>.<无padding的base64url>`。

魔数/版本合为 GFS1，算法白名单只有 WHATWG CompressionStream 的 `deflate`（RFC1950 zlib 包装，非 ZIP、非 deflate-raw）。先序列化原有 glyphforge v1–v7 JSON 包，再压缩；不改 IR、节点参数、资源 manifest 或原 JSON 文件入口。省略可选 undefined 字段等行为与原 JSON.stringify 一致。原包属性/数组顺序保留；同一运行时重复编码一致，**不承诺不同浏览器/压缩实现产生逐字节相同的压缩流**。接收方按解压内容校验和原格式验证兼容。

SHA-256 覆盖解压后的确切 UTF-8 字节；同时核对声明长度。它用于发现损坏，攻击者能重算，不证明发送者、发布者、官方认可或真实性，也不是加密。压缩码可被任何获得其内容的人解码。

参考 [WHATWG Compression 标准](https://compression.spec.whatwg.org/)：deflate 的 ADLER32、截断和尾部多余数据由原生 API 拒绝；额外 SHA-256 检查解压后的内容。没有自行实现另一个解压器。

## 资源与执行预算

| 边界 | 本轮值 |
| --- | --- |
| 输入字符 | 最多 87,500，ASCII 严格正则，禁止空白、padding、非 base64url、未知魔数/版本/算法 |
| 压缩数据 | 最多 65,536 字节；先检查编码长度，再 atob；重新编码拒绝非规范尾位 |
| JSON | UTF-8 最多 1,048,576 字节；声明超限立即拒绝 |
| 原生解压输入 | 每次 128 字节，源高水位 0；逐个输出 chunk 检查累计大小与声明长度，超限取消上游，在 JSON.parse 前拒绝 |
| JSON 结构 | 扫描字符串转义后限制结构深度20；guardJSON 限150,000值/节点、保留原型键/非JSON对象检查；顶层仅允许原分享格式字段 |
| 任务 | 每个专用一次性 Worker；主线程8秒硬终止（包括IDB导出/序列化/哈希/预览）；最多2个并行任务，第三个拒绝 |
| 资源 | 只按ID bulkGet 读取至多100项/12层闭包元数据；累计1MiB上限；读取快照时累计预算到限即停止，不先读满15MiB再尝试分享码 |

小块输入限制一次原生扩张，背压防止一次性展开整颗炸弹。JS保留的解压输出最多1MiB；汇总时另分配至多1MiB连续数组。还存在输入、UTF-16文本、解析对象、structured clone和原生 codec 内部缓冲，不把该上限称为进程内存硬限制。导出行读取沿用256条分页，可能多持有一个分页；浏览器原生分配、IDB、GC没有可移植的精确内存限额。专用Worker终止、总时限、结构与字节上限共同限定任务。两任务的内存预算相加。真实堆样本与未测RSS见验收。

序列化、哈希、base64、结构扫描、JSON.parse、协议预览均在Worker；主线程仅先检查有界文本、启动/取消、显示结果与用户确认后的旧导入事务。解码不递归识别内层 envelope，不自动解压字符串或执行嵌入内容。运行历史/收藏不是工作流包，顶层未知字段拒绝。变异器可保留旧格式已有的父来源引用，但分享不恢复对应 run/generated/favorites，也不把引用伪装为导入设备的执行历史。

## 预览与原子导入

`decode → previewShare → importPackage(..., preview=true)`。复用原 v1–v5 或 v6/v7 的字段、参数、算子版本、资源快照、依赖、DAG、扩展验证。新增 preview 参数只在原写事务前返回；不会安装包或添加任何资源/工作流。扩展声明与同ID/version内容冲突在预览检查。

依赖缺失时，旧校验器抛 ResourceDependencyError，预览明确标为“预检未完成，需绑定”。不假称已完成所有依赖校验。用户确认后进入现有 ImportBindings；绑定后重新运行完整旧导入逻辑。在数据库事务中重新核对本地版本，任何中途错误整体回滚；导入资源、工作流分配新ID，避免覆盖已有用户数据。v6/v7保持其原重绑定/子图ID契约，不另做迁移。收藏与运行表不由分享导入写入。

v7仍只允许P2-D白名单声明流水线，未知包/不匹配版本/不完整闭包/任意JS权限拒绝。已禁用的包保持禁用；未知发布者新安装保持禁用。原有精确内置声明可按旧策略启用，但这是与本地打包内容比较，不由SHA或自报publisher决定信任。未提供自动升级、远程JS或第三方执行入口。

## UI与生命周期

现有分享面板增加轻量/便携模式、生成、只读文本与字符数/压缩后比例、复制、粘贴预览、确认。默认轻量不带快照；便携严格沿用上方勾选ID，未选词库仅在依赖清单出现，不导出词条。动态定义与Mapping快照也须勾选，其传递词库未选仍需绑定。预览列名称、格式、节点/子图数量、资源类型/版本/缺失/本地冲突、扩展安装和启用状态。

新任务、模式或勾选变化、工作流变化、面板卸载都会终止旧Worker；迟到消息不提交UI。复制支持取消后抑制通知，但浏览器已交给操作系统的 clipboard.writeText 无法撤回，界面和验收如实说明。文件导出也在取消后阻止下载与迟到通知。确认后的原子导入不是可撤销解码任务，不在写事务中途强制终止。

大包/不支持API提示下载JSON或本地保存；不尝试把长码塞进URL/二维码。没有URL片段入口、自动读取地址、短链、上传、后端、ZIP或二维码。地址/历史/访问日志不包含分享码。移除原Google Fonts远程CSS，使用已有字体栈的系统回退；离网时保留本地HTTP即可运行和刷新，不提供关闭本地服务后的PWA启动。复制是用户显式操作，系统剪贴板历史/跨设备同步由用户系统管理。

## 兼容与接续

能力检测覆盖CompressionStream/DecompressionStream构造及SHA-256安全上下文；缺失时清楚回退JSON文件。仅真实生产Chromium验收，Firefox/WebKit及实物低端未测，不能据标准可用性宣称已验收。schema仍为7；旧v1–v7 JSON入口与原P0–P2-F执行器、来源/估算逻辑不变。

下一阶段优先跨浏览器/真低端、原生内存峰值与更大包的分段文件处理；URL、二维码、在线功能另立范围。G/Q、全局Entry与通用高级剪枝继续延期。
