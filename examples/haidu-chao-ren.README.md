# 海都潮人 ID · GlyphForge 专项 v2

在左侧点 **海都潮人 ID**。第一次点击会用现有便携包导入器安装独立资源，之后打开同一工作流。默认是简洁生成界面；点击 **编辑** 才进入完整节点、NameScript、结构化 AST 与资源编辑器。刷新重新进入普通模式。

也可在原工坊中「导入」本目录的 [便携 JSON](haidu-chao-ren.portable.json)。导入会创建新的资源和工作流 ID，不覆盖已有内容。初版从旁边 `GlyphForge-M2-preview` 工作区复制保留为 `haidu-chao-ren.v1.portable.json`，没有修改那份工作区。

## 词库与配方

| 独立资源 | 数量 | 用途 |
| --- | ---: | --- |
| 双字核心 | 320 | 海洋、赛博、网络、人设、情绪、动物、质感、荒诞，各 40 项 |
| 单字尾缀素材 | 129 | 扩充搭配的素材池，不做全量随机拼接 |
| 单字前缀素材 | 65 | 同上 |
| 双字搭配素材 | 240 | 同上 |
| 精选搭配关系 | 1,199 | 尾缀 960、前缀 75、语义 25、反差 29、四字 40、实验重复/镜像/叠字 70 |

默认仅输出二字、三字，支持双字直出、核心加尾缀、前缀加核心、语义与受控反差。四字搭配和重复/镜像/叠字在高级选项中独立开启。开启四字实验会把允许字数扩展到 4；点击上方字数切换可恢复二字/三字限制。

示例：海盐、失真、反骨仔、海盐糖、老咸鱼、布丁鲨、海盗电台、猫猫。最后两项分别需要高级四字和实验重复配方。例子表示语料支持，不保证每个种子首批出现。

## 日常使用

- **生成 ID**：按当前种子和条件重新抽取首批。**继续抽取**：同一排序的下一页，条件和资源未变时不重复。**换一批灵感**：种子加一；不同种子之间可能遇到相同候选。
- 字数与风格筛选在执行器输出限额前生效；高级选项提供数量（1–200）、种子、包含字符、排除词条和配方。排除多项用空格或中英文逗号分隔；包含字段作为完整子串匹配。
- 首轮按类别轮流输出，每个核心先出现一次，再提供同核心变体。全部候选不足时返回实际数量，不填充随机汉字。
- 点击名字复制；星星收藏/取消收藏；勾选后批量复制；「导出喜欢的」导出本工作流收藏的纯文本。不同运行同名收藏沿用原有来源冲突保护。
- 「×」反馈可排除整个结果或关系的左/右词；排除列表保存到工作流，可在高级选项撤回。「↻」按该结果的风格换种子生成。
- 底部「运行历史与留存」沿用既有运行记录、分页、固定与备份。历史保留设置沿用全局策略。

## 编辑和扩充

点击「编辑」进入原有完整工坊，「生成预览」运行当前已应用的图。「保存并返回」会校验并应用当前 NameScript，成功保存后返回生成界面；语法无效时留在编辑模式并报错。「返回生成（保留草稿）」保留会话内未应用代码，再点编辑即可继续；刷新前仍使用原有未保存警告，未应用代码不承诺跨刷新恢复。

在「编辑词库」或资源中心中找到 **海都潮人 · 精选搭配 · 导入**。可逐行增删改、标签分类、修改权重，或批量导入/导出。运行依据为显式关系，不从素材池盲目生成笛卡尔积：素材池改名/增删不会自动改写已审核关系。新增词请同时添加合适关系；运行后生效，无需改程序。

- `left` / `right`：实际拼接的两端；两字左端也可以直出。
- `风格:海洋` 等标签：决定分类；新增 `风格:你的分类` 后界面自动列出。
- `配方:suffix`、`prefix`、`semantic`、`contrast`、`double`、`echo`：决定配方。`direct` 根据二字左端直出识别。
- `weight`：0–100 排序质量分。默认分数是可检查的六维启发式：语义 30%、读音 20%、视觉 10%、潮流 20%、反差 10%、撞名风险 10%；`note` 保存分项。这里没有自动语言学模型，也没有查询服务器真实重名数据。编辑器修改权重不会自动重写分项备注。
- 关系均为有向，不自动把左右互换；同一左右词及关系方向只能有一行，避免违反已有唯一索引。

底部四个素材节点保留在原依赖模型中，便携导出会携带这些独立池；它们不连接结果输出。上方 program → 精选与多样性 → output 是实际执行路径。完整工坊仍支持增删节点、连接、撤销、子图和导入导出。删掉精选节点后会使用你编辑的原图，普通界面中相关筛选会停用。

作者用独立 [catalog JSON](haidu-chao-ren.catalog.json) 维护原始词池与逐项搭配，运行 `node scripts/export-haidu-chao-ren.mjs` 可重新生成随项目分发的便携包。此命令只构建文件，不读取或改写用户浏览器数据库。浏览器内用户自定义请从原分享面板导出便携包，包含标签、评分、方向、备注和资源版本。

## 质量规则与边界

优先常见字、二三字节奏、可辨认的玩家口吻，控制海洋占比，不使用仙侠称谓堆砌。词对来自逐项选词，而非随机汉字组合；构建器再过滤重复和字形接缝冲突。评分用于候选排序，加固定种子扰动，并按类别轮流取样；它不是人工玩家验收证明。

[腾讯文档参考](https://docs.qq.com/sheet/DSGdpdFhlRXdMQWlv) 此前工具访问不可读；发布前已用用户提供的 Excel 核对双字直出、1+2、2+1 组合思路，没有复制原始词库或上传该工作簿。语料仍需真实 FF14 玩家主观审读。二三字输出是否适合具体服务器注册，应由游戏实际规则与可用性决定。

精选节点每次最多扫描 10,000 个上游候选，受原 300,000 步/10 秒 Worker 预算约束；超限明确报错，不静默截断到某一类。program 通常每条关系产生左端及组合两项，因此实际可用关系行数要低于这个候选上限；更大资源可在编辑器先分组/筛选。

实测、已知限制及修改文件见 [专项验收](../docs/HAIDU-RELEASE-20261108.md)。便携包含资源，不含收藏与历史；二者继续使用原有备份方式。
