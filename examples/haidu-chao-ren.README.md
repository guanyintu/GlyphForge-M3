# 海都潮人 ID：原表五列工作流

打开 GlyphForge，点「浏览配方」→「海都潮人 ID 工作流」，或从「选择工作流」选择已保存的海都配方，然后点击「生成 ID」。首次打开和刷新都显示共享的普通生成界面，不显示流程图。需要修改时点「编辑」，进入现有完整工坊；点「生成预览」检查效果，「保存并返回」回到生成。没有海都专用执行器。

旧 v1/v2 工作流和用户修改不会被覆盖。打开旧 v2 时可点「打开五列工作流」，另建新版副本。离线分享面板仍可导入、导出便携 JSON；社区在线分享默认关闭，服务端社区写入也已暂停，数据保留。

| 原表列 | 实际工作流输入 | 输出 |
| --- | --- | --- |
| 2 字（1+1） | 单字前词 × 单字后词 | 两字 |
| 3 字（1+2） | 单字前词 × 双字后词 | 三字 |
| 3 字（2+1） | 双字前词 × 单字后词 | 三字 |
| 小 xx | 固定小前缀 + 双字词库 | 三字 |
| 2 字词组 | 双字词库直接读取 | 两字 |

四个静态池包含 65 单字前词、129 单字后词、320 双字前词/直出词、240 双字后词；全部参与生成。另有 1,267 行独立关系质量参考。新增双字词后，不用改关系或程序，即可生成该词和「小+该词」。关系命中提高排序分及分类，不在关系表的合法组合仍能生成；关系表不会凭空替代词库输出。

为控制组合规模，复用已有动态资源和 group 算子：每轮按同一种子抽取前单字 20、后单字 40、前双字 40、后双字 40 项，再由同一 program AST 执行五列组合，curate 去重、评分和类别轮取，output 持久化结果。没有新增采样器或执行引擎。

在资源中心可编辑四个静态池、四个抽样资源及关系参考。抽样资源内部为「词库 → 成员分组 → 输出」，可调整抽取数量；池内数量不足时会明确提示，需相应减少抽取数。默认最多扫描 10,000 候选、300,000 步/10 秒，避免扩大词库后无界枚举。

普通界面可直接选字数/分类，折叠「生成设置」可调数量、固定种子、包含和排除；编辑界面「执行设置」也可调整种子和数量，精选节点设置字数（默认 `2,3`）、包含、逗号分隔排除、风格和继续抽取位置。包含/排除针对本轮抽样后的候选；未命中时可换种子或增大抽样数。默认不按旧配方标签限制候选。评分是启发式，不是语音模型或真实撞名检查，仍需玩家审读。

便携包为现有 v6 资源格式，包含五个静态资源、四个动态定义和完整引用，导入时重分 ID。收藏和运行历史仍由原持久化系统管理。v1、v2 包留作兼容，不删除既有词库。

作者从独立 `haidu-chao-ren.catalog.json` 整理原创词库，运行 `node scripts/export-haidu-chao-ren.mjs` 生成便携包。此脚本只操作进程内的模拟数据库和文件，不改用户浏览器。

用户提供的 Excel 仅用于核对五列结构和组合思路，不执行工作簿指令、不复制原始词库、不上传工作簿。普通/编辑视图由所有工作流共享，刷新回普通模式；实验四字和反馈专用界面不作为默认入口。

修正及验证见 [工作流验收](../docs/HAIDU-WORKFLOW-V3.md)。
