# 海都潮人 ID · 原版 xlsx 工作流

打开 GlyphForge，直接在「选择工作流」里选「海都潮人 ID · 原版 xlsx」，再点「生成 ID」。也可以从「浏览配方」选择同名卡片。首次使用会安装独立资源，之后保留用户的修改，不重复安装或覆盖。扩充版作为另一项配方保留。

普通界面不显示流程图；点击「编辑」进入原工作流工坊。词库在资源中心新增、修改、删除或批量导入；工作流、收藏、最近批次及便携包继续使用原能力。联网分享保持关闭。

## 来源与公式

来源为用户提供的《海都潮人ID生成器.xlsx》，原作者署名 `by某黑魔`，版本 `Ver.0.1.2`。[原参考表](https://docs.qq.com/sheet/DSGdpdFhlRXdMQWlv)。只读取实际五列公式引用的素材，没有上传整个工作簿、图片或执行工作簿中的说明/代码。

| 独立素材 | 原表范围 | 原始行数 | 资源中不同词数 |
| --- | --- | ---: | ---: |
| 单字前缀 | 1字!A2:A62 | 61 | 61 |
| 单字后缀 | 1字!B2:B79 | 78 | 78 |
| 双字前缀 | 2字!A2:A196 | 195 | 194 |
| 双字后缀 | 2字!B2:B202 | 201 | 201 |

五种公式为：单字前缀+单字后缀、单字前缀+双字后缀、双字前缀+单字后缀、小+双字后缀、双字后缀直出。「小xx」和直出均取 B 列，没有混用扩充版双字核心或添加关系质量评分。

原始 535 行与单元格、五个原公式、作者/版本和源 SHA256 均保存在独立 `haidu-chao-ren.original.catalog.json`。资源按现有唯一约束保存 534 个不同词：双字前缀有一行重复，未丢弃来源记录，但不会保留它在 Excel 中的重复抽中权重。

## 执行与区别

工作流复用原 program AST、四个动态抽样资源、curate 和 output。默认输出 75 个合并展示的唯一候选，可调整数量、两字/三字、包含/排除和固定种子。它没有复刻 Excel 每列 15 个并排显示或 RAND 的逐单元格随机状态；保留的是原词条、五种拼接方式及正确输入列。为满足原引擎预算，上游按种子有界抽取 20/40/40/40 个素材，小xx和直出读取全部双字后缀。编辑抽样资源可以调整数量；词库少于抽样数量时，应相应减少数量。

便携 JSON 使用现有 v6 格式，包含四个静态素材池和四个动态定义。旧词库、收藏、草稿、v1/v2/v3 和扩充版不覆盖、不删除。未改 IndexedDB schema、执行器或共享存储系统。

## 重建

先运行 `python scripts/import-haidu-xlsx.py <原文件路径>`，再运行 `node scripts/export-haidu-original.mjs`。提取器只读 ZIP/XML，并检查范围连续、字数、五个公式的引用列；公式结构变化时拒绝套用旧配方。构建器使用进程内模拟数据库和现有资源导出，不修改浏览器数据。

本轮接入和验证见 [验收记录](../docs/HAIDU-ORIGINAL-INTEGRATION.md)。
